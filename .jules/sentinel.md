## 2024-05-18 - [XSS in Chart Tooltip innerHTML Assignment]
**Vulnerability:** The Angular dashboard frontend (`src/app/shared/models/chart-tooltip.ts`) directly assigned unsanitized strings (`title` and `body` arrays derived from `tooltip` data) to `.innerHTML` of a table element. This bypasses Angular's built-in `DomSanitizer` protections, leading to a Cross-Site Scripting (XSS) vulnerability.
**Learning:** Even within an Angular application where template bindings (`[innerHTML]`) are partially sanitized, direct DOM manipulation via `.innerHTML = ...` skips all framework-level sanitization entirely. Data source for tooltips must be assumed untrusted or at risk of containing malicious payloads.
**Prevention:** Always sanitize or escape any dynamic data before directly assigning it to `.innerHTML`. When using libraries like lodash in this project's TypeScript configuration, use `import * as _ from 'lodash';` and `_.escape(value)` for robust escaping of HTML entities.
