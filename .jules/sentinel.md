## 2024-05-19 - XSS in Angular Chart Tooltips
**Vulnerability:** Cross-Site Scripting (XSS) vulnerability found in `src/pybind/mgr/dashboard/frontend/src/app/shared/models/chart-tooltip.ts` where unescaped chart labels (titles and body texts) were being concatenated into an HTML string and assigned to a DOM element's `innerHTML`.
**Learning:** Even though Angular generally protects against XSS when using standard template bindings, direct DOM manipulation (e.g., using `element.innerHTML = ...`) completely bypasses Angular's `DomSanitizer`. This pattern is sometimes seen in integrations with 3rd-party non-Angular libraries like Chart.js that provide custom rendering callbacks.
**Prevention:** Always sanitize or escape user-controlled data before assigning it to `innerHTML` or similar sinks when performing manual DOM manipulation. In this codebase, we can use `lodash`'s `_.escape()` function as a simple way to HTML-escape text content before concatenation. Remember to use `import * as _ from 'lodash';` due to the project's TypeScript configuration.
