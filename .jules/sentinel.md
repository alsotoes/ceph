## 2025-02-14 - Angular XSS Bypass via innerHTML Property Assignment
**Vulnerability:** Raw assignment to `tableRoot.innerHTML = innerHtml` within the Angular application completely bypassed Angular's `DomSanitizer`, creating a Cross-Site Scripting (XSS) risk if `innerHtml` includes unsanitized user-supplied inputs, such as chart titles or values.
**Learning:** In Angular components, raw DOM API manipulations (like `ElementRef.nativeElement.innerHTML = ...`) are outside of the framework's automatic template sanitization. Relying entirely on Angular's context without reviewing direct DOM assignments can result in silent XSS vectors.
**Prevention:** Avoid direct DOM manipulation for HTML assignment when possible. When necessary, explicitly sanitize any inputs embedded into raw HTML strings. The `lodash` library's `_.escape()` utility should be used to securely escape properties appended to raw HTML strings. Use `import * as _ from 'lodash';` to adhere to standard configuration.
